readme-start refreshes what it generated (new dependencies, new scripts…) and keeps the rest.

    Vos sectionsYour sections Un titre qu'il ne génère pas (« FAQ », « Captures d'écran »…) reste à sa place et entre dans le sommaire. A heading it does not generate ("FAQ", "Screenshots"…) stays where it is and joins the table of contents.

    Vos blocs protégésYour protected blocks Tout ce qui est entre deux marqueurs revient exactement entre les mêmes paragraphes. Anything between two markers comes back exactly between the same paragraphs.
